Built like a product

A real-time 3D driving game wrapped in an AI backend: agent, retrieval, vision and a hardened container.

Agentic AI coach

A planner picks tools (RAG search, run analyser, vision scan), runs them and returns the answer with a visible step trace. An AI Director then tunes traffic for your next run.

Hybrid RAG

TF-IDF retrieval over a driving-rules knowledge base, with cited sources in every answer.

CNN-style vision

Upload a road photo: Sobel convolutions, ReLU and pooling estimate scene complexity. Heuristic kernels, not a trained model.

Garage progression

Earn coins, then upgrade engine, tyres, nitro cell and fuel tank. Bloom, chromatic aberration, gamepad support and snapshot capture included.

Security & limits

  • CSP, HSTS, nosniff, frame deny
  • 60 req/min per IP, 2 MB uploads
  • Strict input validation
  • Non-root, read-only Docker

Ask the Garage coach

Runs on the FastAPI backend. On static hosts (Vercel, Netlify) it falls back to a built-in offline answer.
